# Federated Learning Phishing Detection - Project Division

## 4-Member Team Collaboration Structure

This repository contains the project division for a federated learning phishing email detection system, organized for collaborative development with 4 team members.

---

## 🎯 Quick Start

1. **Choose your role**: Member 1, 2, 3, or 4
2. **Read**: `QUICK_START.md`
3. **Go to your folder**: `member1/`, `member2/`, `member3/`, or `member4/`
4. **Read**: Your `README_MEMBERX.md`
5. **Start coding**: Work on your assigned files

## 🚀 Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/hemanth-jayaram/testing.git
cd testing
```

### 2. Read Documentation
```bash
# Start here
cat QUICK_START.md

# Your specific role
cat member1/README_MEMBER1.md  # or member2, member3, member4
```

### 3. Create Your Branch
```bash
# Member 1
git checkout -b feature/federated-learning

# Member 2
git checkout -b feature/cloud-infrastructure

# Member 3
git checkout -b feature/web-interface

# Member 4
git checkout -b feature/data-documentation
```

### 4. Start Working
```bash
# Edit your assigned files
# Commit regularly
git add <your-files>
git commit -m "feat(scope): description"
git push origin <your-branch>
```
